# Results

Results are grouped by experiment and input type. Most generated outputs (full videos, per-frame CSVs, checkpoints, and experiment folders) are excluded from Git; selected report figures are copied to the root `photos_for_readme/` directory.

- `experiments.md`: recorded local runs and their caveats.
- `full-model/`: HSI adapter training, HSI tracker test outputs, and metrics.
- `cnn_adapter_testing/`: CNN prompt activation and pseudo-RGB diagnostics; some prompt maps are from untrained initialization.
- `convolution_testing/`: initial spectral projection checks and video.
- `runs/`: RGB/false-color ViPT or SAMURAI example outputs, not HSI adapter metrics unless explicitly labeled.
- `plots/`: stand-alone demo metric curves.
- `visualizations/`: sequence preview imagery.
